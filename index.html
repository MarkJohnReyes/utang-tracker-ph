Bulk Import Borrowers & Utangs (Excel)

Upload an .xlsx, .xls, or .csv file. Each row can represent a borrower, a loan, or both. Existing borrowers with matching names are reused rather than duplicated.

Recommended column headers:
borrower_name, phone, borrower_notes, amount, date_borrowed, due_date, term_value, term_unit, interest_enabled, interest_rate, interest_period, loan_notes.
Required: borrower_name. For an utang row, include amount and date_borrowed. Dates should use YYYY-MM-DD or valid Excel dates. One row per loan; repeat the borrower name for multiple loans.

Merge Duplicate Borrowers

Choose the borrower record to keep and the duplicate record to merge into it. All loans will be reassigned to the kept borrower before the duplicate is deleted. Payments remain attached to their original loans.
